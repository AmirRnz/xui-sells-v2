# Requirements Traceability Matrix (P01 – P25)

This document tracks every product requirement from the authoritative specification to its architectural module, database schema, presentation layer, and verification test suite.

| Req ID | Title & Summary | Core Module / Package | Database Tables | Presentation (Bot / Web / CLI) | Test Suite |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **P01** | **Product Scope**<br>Sell VPN subscriptions to ordinary customers and resellers via Telegram bots. Single integrated system with child bots, web panel, and host CLI. | `internal/app/instance`, `internal/adapter/telegram` | `instances`, `reseller_profiles` | Telegram bot supervisor, Web panel, CLI `instance` commands | `TestInstanceSupervisor`, `TestMultiBotLifecycle` |
| **P02** | **Ordinary-Customer Free Trials**<br>Free trials per plan, configurable traffic allowance and duration. Waiting period (cooldown) and quota window (e.g. 2 per week).
